Alura & GitHub setup

Connect your Etsy shop in Alura, then keep its API key on the private app server.

Alura connection

Alura is not connected to the app yet.

  1. Alura Settings → Etsy shops: connect your Etsy shop through Etsy’s approval page.
  2. Alura Settings → API keys: create a key with shop read, listings write and keyword research access.
  3. Set the key on the app server as ALURA_API_KEY. Never paste it into this web page or commit it to GitHub.
  4. For generated mockup photos to reach Etsy through Alura, the hosted app needs a public HTTPS image address.
